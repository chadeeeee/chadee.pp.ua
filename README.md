# chadee.pp.ua — портфоліо

Vite + TypeScript + Three.js + GSAP (ScrollTrigger) + Lenis.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # готовий сайт у dist/
```

## Що редагувати

Увесь контент лежить у [`src/data.ts`](src/data.ts): контакти, навички, проєкти й посилання для підтримки.

- `SUPPORT.monobankJar` — встав посилання на банку (`https://send.monobank.ua/jar/...`), і зʼявиться картка «Банка Monobank».
- `SUPPORT.usdtTrc20` — адреса гаманця. Зʼявиться картка з кнопкою «скопіювати».
- Щоб додати проєкту кнопку, вкажи `live` (сайт) або `repo` (публічний репозиторій). Без них проєкт показується з позначкою «🔒 приватний».

## Файли

- `src/scene.ts` — 3D-фон: рідкий іридесцентний блоб (шейдер із simplex-шумом), галактика частинок, кільця, літаючі багатогранники. Блоб перелітає на нове місце для кожної секції.
- `src/hypercube.ts` — справжній n-вимірний гіперкуб (3D–15D), що обертається в ℝⁿ і проєктується на екран.
- `src/main.ts` — прелоадер, інтро, курсор, магнітні кнопки, 3D-нахил карток, анімації на скролі та горизонтальна карусель проєктів.

## Деплой на Vercel

Framework preset: **Vite**, build command `npm run build`, output `dist`.
